# LuKo - Garden Equipment Rental & Service Platform

A modern, high-performance landing page designed for **LuKo**, a company specializing in garden equipment rental, maintenance, and professional landscaping services. This project focuses on speed, accessibility, and a bold visual identity to drive customer conversions.

## 🚀 Tech Stack

- **Framework:** [Astro 6.1](https://astro.build/) (Island Architecture for maximum performance)
- **Styling:** [Tailwind CSS 4.2](https://tailwindcss.com/) (Using the latest `@theme` and CSS-first configuration)
- **Deployment:** Firebase / Static Hosting
- **Language:** HTML / CSS / TypeScript (Client-side scripts)

## ✨ Key Features

### 1. Dynamic Hero Section

An immersive entry point featuring:

- **Floating Decorative Elements:** High-quality garden equipment images (PNG) positioned with responsive logic to "frame" the brand name without obstructing readability.
- **Custom Animations:** Smooth, non-blocking CSS floating effects (`animate-float`) to add life to the static page.
- **Smart Responsive Positioning:** Advanced Tailwind breakpoints (`sm`, `md`, `lg`, `xl`, `2xl`) ensure the layout adapts perfectly from the smallest mobile devices to 4K monitors.

### 2. Interactive Conversion System

- **Contact Overlay:** A custom-built modal system for phone number confirmation, preventing accidental dials while providing a clean UI.
- **WhatsApp Integration:** Direct booking links for each equipment item, pre-filling messages for better user experience.

### 3. Equipment Catalog

- A clean, grid-based layout displaying the rental fleet.
- Card-based design with price transparency (4h vs 24h rates) and deposit details.
- Visual feedback on hover to emphasize interactivity.

### 4. Performance & SEO

- **Zero JS by default:** Leverages Astro's power to ship minimal JavaScript.
- **Optimized Assets:** Uses Astro's image optimization pipeline for fast loading times.
- **Semantic HTML:** Structured for SEO and accessibility (address tags, proper heading hierarchy).

## 🛠️ Installation & Setup

To run this project locally, ensure you have **Node.js v22.12.0** or higher installed.

1. **Clone the repository:**

   ```bash
   git clone [your-repository-url]
   cd Page
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📐 Design Philosophy

The design uses a high-contrast **"Luko Green"** and **"Luko Yellow"** palette to reflect professional garden services. The typography (Black Italic headings) conveys speed, reliability, and heavy-duty performance.

## 📝 Project History

This project was developed as a real-world implementation for a local business in Pyrzyce, Poland. It demonstrates the ability to translate a brand's physical identity (based on their Facebook presence and logo) into a functional, modern web experience.
